# STM32 LL + Register LED Blink

My first attempt at working with STM32 **without the HAL library**, combining LL (Low-Layer) drivers with direct register access. It blinks the on-board LD2 LED (PA5).

> 🔰 This is a learning project. It's my first step moving from HAL to LL + register-level programming, so the code is intentionally simple and open to improvement.

## What it does

- Configures the system clock from the HSI48 source at 48 MHz (`LL_RCC_*`, `SystemClock_Config`)
- Sets up PA5 (LD2) as push-pull output via `LL_GPIO_Init`
- In the main loop, toggles the LED by writing directly to the `GPIOA->BSRR` register (`GPIO_BSRR_BS_5` / `GPIO_BSRR_BR_5`)
- Uses a simple `volatile` counter loop for delay

## Tools used

- STM32CubeMX (for project scaffolding and pin configuration)
- LL (Low-Layer) drivers
- Direct register access (BSRR)

## Why this repo?

I wanted to document the first step in understanding what happens underneath the HAL abstraction. It might serve as a small but readable reference for anyone on the same path.

## Hardware

- STM32F072RBT6 Nucleo board
